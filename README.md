# Hope of Living Website

## WEDE5020: Web Development (Introduction)

### Project Overview

Hope of Living is a community-focused website created for the WEDE5020 Web Development module. The website is designed to provide information about Hope of Living, its purpose, services and community activities.

The organisation is based in Lower Philippi, Cape Town, and focuses on supporting people in the community and creating hope through community involvement.

## Purpose of the Website

The purpose of this website is to:

* Introduce Hope of Living to visitors.
* Provide information about the organisation.
* Explain the services and support provided.
* Display images of community activities.
* Provide contact information for people who want to get involved or make enquiries.

## Website Pages

The website contains the following pages:

* **Home** – Introduces Hope of Living and provides an overview of the organisation.
* **About Us** – Provides information about the organisation, its vision and values.
* **Services** – Describes the services and community support provided.
* **Gallery** – Displays images related to the organisation and its activities.
* **Contact Us** – Allows visitors to send an enquiry and find information about contacting the organisation.

## Technologies Used

The website was developed using:

* HTML5
* CSS3
* Responsive web design
* Git and GitHub
* Apache NetBeans

## Website Features

The website includes:

* A navigation menu linking all pages.
* Consistent styling across the website.
* Responsive layouts for different screen sizes.
* Image gallery.
* Contact form.
* Hover effects.
* Flexible layouts using CSS Flexbox and Grid.
* Media queries for mobile and tablet devices.

## Responsive Design

The website uses CSS media queries to make the pages responsive. The layout adjusts when the website is viewed on smaller screens such as tablets and mobile phones.

The navigation, cards, images and content sections are adjusted to improve readability and usability on different screen sizes.
